## 🛠️ Local Compilation

### Prerequisites

Ensure you have a TeX distribution installed on your system:

- **Linux (Debian/Ubuntu)**:
  ```bash
  sudo apt install texlive-latex-base texlive-latex-recommended texlive-fonts-recommended texlive-latex-extra
  ```
- **macOS**: Install [MacTeX](https://www.tug.org/mactex/) via Homebrew:
  ```bash
  brew install --cask mactex-no-gui
  ```
- **Windows**: Install [MiKTeX](https://miktex.org/) or [TeX Live](https://www.tug.org/texlive/).

### Build PDF

Run `pdflatex` from the root directory:

```bash
pdflatex -interaction=nonstopmode Titanio_Yudista_resume.tex
```

To automatically resolve cross-references and clean up auxiliary files with `latexmk`:

```bash
latexmk -pdf -interaction=nonstopmode Titanio_Yudista_resume.tex
```

### Clean Build Artifacts

To remove auxiliary build files generated by LaTeX:

```bash
rm -f *.aux *.log *.out *.fls *.fdb_latexmk *.synctex.gz
```
